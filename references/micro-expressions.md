# 微表情参考

将情绪写成模型可观察到的短暂面部变化，而不是只给抽象标签。每个连续镜头段落选用 1–3 个相互一致的细节；关键转折按“触发 → 瞬时反应 → 稳定后的表情”书写。除非剧情明确需要，不要叠加眼泪、大幅哭泣、夸张张嘴、频繁眨眼或大幅摇头。

## 写法

使用这个句式：`[触发] 后，她先 [眼神/眉部细节]，再 [嘴角/唇线细节]；[停顿或呼吸] 后，表情稳定为 [下一情绪]。` 在面向用户的互动段，加上`面对镜头`或`看向镜头`；回避时只写明确场景目标，随后写明恢复看向镜头的时点。

示例：`听到道歉后，她先把停在窗外的视线收回，眉间的轻微紧绷慢慢松开；她抿住的唇线放松，呼吸变缓，随后重新面对镜头，但没有立刻微笑。`

## 常用情绪组合

| 场景情绪 | 可直接调用的细节提示词 | 适用节奏 |
|---|---|---|
| 温柔微笑 | 嘴角轻轻上扬，眼神温和柔软，眼尾微微向下，眉毛舒展放松，头部轻微侧倾 | 开场、安抚后的轻笑 |
| 害羞微笑 | 嘴角轻抿带笑，脸颊轻微泛红，视线略微偏开不直视镜头，眼睫轻垂 | 被夸赞、亲近互动 |
| 认真思考 | 眉头轻轻皱起，目光聚焦，眼神专注前方，嘴唇自然闭合或轻抿，头部微低 | 聆听、权衡、回应前 |
| 疑惑不解 | 一侧眉毛轻轻上挑，另一侧自然压低，眼神带探索感，嘴唇微张或轻抿，头略偏向一侧 | 听到意外内容 |
| 委屈忍耐 | 眼眶微微泛红但不落泪，眉头轻微并向中间靠拢，嘴角略向下，唇线收紧，努力维持平静 | 生气前的受伤、忍耐 |
| 难过落寞 | 眼神失焦或微微下垂，眉毛轻轻内收，嘴角自然下垂，肩颈放松带一点疲惫 | 沉默、空镜前后 |
| 生气压抑 | 眉头紧锁，眼神变冷，嘴唇抿紧，嘴角微微向下，面部肌肉有轻微压迫感；情绪像被压住而非爆发 | 克制争执、失望 |
| 强忍愤怒 | 眉骨压低，眼神冷静，唇线紧绷，可见轻微咬牙后放松，下颌线略微绷紧 | 需要忍住火气的回应 |
| 吃醋不悦 | 眉头轻皱，眼神有一点别扭和不高兴，嘴角轻抿，脸颊微微偏开，像装作不在意 | 轻松关系戏 |
| 惊讶 | 双眼微微睁大，瞳孔有明显亮光，眉毛上扬，嘴唇微张；一瞬后恢复克制 | 意外消息、转折触发 |
| 心动瞬间 | 双眼微微睁大，瞳孔发亮，脸颊轻微泛红，嘴唇轻张后缓缓合上，神情短暂停顿 | 被真诚表白或安慰 |
| 嘴角轻颤 | 眼里带泪但不流下，嘴角有细微颤动，眉头轻皱；像快哭出来却仍在忍 | 受伤被看见的瞬间 |
| 眉头轻动 | 眉心微微一动，眼神短暂聚焦，嘴唇保持自然；像意识到关键内容后的真实反应 | 细小信息触发 |
| 内心挣扎 | 眉头轻皱，眼神复杂矛盾，嘴唇微微张开又闭合，像有话想说却说不出口 | 道歉后的沉默、选择前 |
| 心软瞬间 | 原本冷淡的眼神慢慢柔和下来，眉眼放松，嘴角有极轻微松动，呼吸变缓 | 从生气转向理解 |
| 被哄后的冷静 | 眼神变得平静，嘴角轻抿，眉头微收；表面平静但情绪已经沉下去，带克制的冷意 | 尚未完全和好 |
| 释然轻笑 | 嘴角轻轻扬起，笑意温和放松，眼神安静平和，眉眼舒展，像终于放下心事 | 和解、结尾 |
| 复杂情绪交织 | 眼神同时带着悲伤、释然和一点笑意，眉眼细微收敛又放松，嘴角轻扬但不完全开心，层次丰富 | 经历情绪转折后的结尾 |

## 生气被哄好的推荐弧线

1. **受伤而压抑**：使用“委屈忍耐”或“生气压抑”；先写回避视线与抿唇，再写眉间收紧。
2. **听到道歉**：使用“内心挣扎”；让目光短暂聚焦，唇线仍紧，不立即笑。
3. **逐渐心软**：使用“心软瞬间”；先松开眉眼，再放慢呼吸和放松嘴角。
4. **保留边界地和好**：使用“被哄后的冷静”；可轻点头，但嘴角只出现极浅笑意。
5. **结尾释然**：使用“释然轻笑”或“复杂情绪交织”；重新看向镜头，停留半秒再自然放松。

## 禁止项

- 不将微表情写成互相矛盾的组合，例如“眉头紧锁且眉眼舒展”“冷漠目光同时温柔含笑”。
- 不在普通对话的每秒都安排眉眼变化；保持表情稳定，只有触发点才发生细小变化。
- 不把抽象心理词当作完整描述；“她很难过”后必须补充可见的眼神、眉部、嘴角或呼吸细节。
- 不要求夸张哭戏、呆滞瞪眼、频繁快速眨眼、反复挑眉，除非用户明确指定该强度。
