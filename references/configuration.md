# 配置字段

首次收到需求时，将用户要求整理为以下字段并输出“制作确认单”。桌面系统、参考图使用范围、成年人物、互动关系和字幕 UI 是必须确认项；其他空字段可给出默认建议，等待用户确认后才进入完整提示词生成。

| 模块 | 字段 | 默认建议 |
|---|---|---|
| 成片 | 时长、比例、分辨率、帧率、平台/模型 | 15 秒或 30 秒；16:9；固定机位 |
| 桌面 UI | 系统、顶栏/底栏、图标密度、桌面洁净度、状态信息、UI 参考图 | 必须确认仅一个 OS；干净桌面；图标需高保真时提示用户提供 UI 截图 |
| 角色 | 成年身份、参考图、锁定属性、性格、情绪曲线、镜头关系 | 成年、自然克制、面向镜头互动 |
| 参考图 | 类型、使用范围、是否可继承服装/场景、人物数量 | 必须预留人物、桌面 UI、场景、服装四类图；分开声明；UI 图默认只锁定系统界面 |
| 场景 | 场地、时间、天气、光色、家具/道具、人物活动区 | 一个稳定主场景；启用字幕 UI 时才留出字幕安全区 |
| 剧情 | 主题、关系设定、冲突或目标、结尾互动钩子 | 一段完整微剧情，结尾留回应空间 |
| 对白 | 语言、女主/男主画外音、台词、语气、口型、停顿 | 中文；男主全程不出镜；台词短；不得抢话 |
| 字幕 UI（可选） | 是否启用、字幕文字、字体样式及女主/男主文字颜色、逐字节奏、停留/淡出、音频波形动效 | 向用户说明可选；启用时只能位于屏幕左侧中部，仅含上述三类元素；每字 0.08–0.12 秒、说完停留约 0.4 秒 |
| 服装 | 初始及后续造型、领口/覆盖要求、饰品、袜鞋、变化方式 | 服装完整、有真实结构；变化在画外完成 |
| 镜头 | 机位、连续镜头、进出方向、景别、空镜、允许特效 | 固定机位；人物仅按指定边缘真实进出 |
| 声音 | 人声特征、BGM、环境声、音效、混音优先级 | 人声最清晰；BGM 自动压低 |
| 交付 | 只要主提示词/需时间轴/是否需 cue sheet/需后期建议 | 主提示词 + 时间轴 + 负面约束；字幕 UI 启用时再提供 cue sheet |

## 主题路由

- **换装/展示**：为每套造型定义完整服装结构、展示动作和画外换装路线；套装数量越多，越应增加时长或减少对白。
- **晨间叫醒/陪伴**：定义角色起始状态、唤醒触发、逐渐清醒的情绪弧线和结束动作；避免大幅动作破坏桌面壁纸的稳定构图。
- **生气/哄好/和解**：定义冲突原因的可见线索、女主沉默的聆听段、情绪转折触发和最后仍可继续互动的余韵。不要让画外音突然替女主说话。
- **其他互动**：先写“男主对女主说什么/女主要回应什么/最后邀请男主做什么”，再选择合适的道具和动作；男主全程只以画外音存在。

## 桌面 UI 参考图

当用户希望 Dock 图标、顶栏、任务栏或窗口视觉接近真实系统时，邀请其提供桌面 UI 参考截图。优先使用无人物、无私密文件、无敏感通知、无鼠标指针、分辨率清晰且构图接近目标画幅的截图；若只需 Dock，可提供底部区域的干净裁切图。

在提示词中明确参考图的职责，例如：`桌面 UI 参考图仅用于复现底部 Dock 的半透明材质、图标排列、大小和位置；不要复制原截图的壁纸、时间、通知、文件名、窗口内容或人物。` 人物参考图与 UI 参考图必须分别标注，防止模型把截图中意外出现的人物或壁纸错误继承到视频中。

## 时长预算

以普通中文语速计算。对话段要为台词、口型和自然反应预留时间；启用逐字字幕时，再计入字幕停留。换装或进出画面要包含真实走动和至少约 0.6–0.8 秒空镜。

| 目标时长 | 建议内容量 |
|---|---|
| 15 秒 | 一个主题转折；2–3 轮极短对话；最多一次画外变化 |
| 30 秒 | 一个完整互动；4–6 轮短对话；最多两次明确画外变化 |
| 45 秒以上 | 可加入更完整情绪弧线或多造型，但仍以单一主场景和有限动作维持稳定 |

若平台限制短片段，建议按连续动作边界拆成多段生成，再在后期拼接；每段首尾复述人物、服装、机位、背景和运动方向锚点。
