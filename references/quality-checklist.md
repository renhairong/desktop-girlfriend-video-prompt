# 质量自检

交付前逐项核对。

## 叙事与时长

- 时间轴首尾相接，总时长与目标一致。
- 每句台词都有足够发音时间，动作不与说话冲突。
- 主题在开场被建立，结尾保留一个可回应的互动点。

## 角色与服装

- 所有阶段是同一名成年角色，锁定属性无漂移。
- 每套服装都有上装、下装、袜鞋/无鞋说明和必要饰品；无模糊的“换一套衣服”。
- 角色的情绪、动作与关系设定一致，不将成年角色表演成幼态。

## 桌面与构图

- UI 只属于指定 OS，顶栏/底栏的位置和风格稳定。
- 使用桌面 UI 参考图时，只继承其指定的系统界面元素，不复制其中的壁纸、文件、通知、窗口内容、人物或隐私信息。
- 启用字幕 UI 时，屏幕左侧中部的字幕安全区从头到尾可用，人物和道具不侵占。
- 桌面干净度与图标策略一致，背景不会随镜头突然变化。

## 连续运动

- 固定机位没有推拉、摇移、切镜或突然景别变化。
- 所有进出发生在指定画面边缘，角色先完整离开再进行画外状态变化。
- 空镜的时长、环境和声音已写清；无瞬移、淡入、身体融化或服装替换闪帧。

## 对白、声音与可选字幕

- 每轮只有一位说话者；另一位闭嘴聆听。
- 启用字幕 UI 时，每句有准确中文文本、角色文字样式及颜色和逐字节奏；结尾停留与淡出明确。字幕区只出现字幕文字、字幕样式及颜色、音频波形动效，不出现麦克风、扬声器、头像、按钮、手部、话筒或实体道具。
- 环境音、音效和音乐低于对白；口型与发音同步。
- 启用字幕 UI 时，精确中文字和复杂 UI 已提供后期覆盖 cue sheet。
