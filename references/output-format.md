# 输出格式

按下列顺序输出，并以用户语言为准。中文项目默认中文。

## 0. 制作确认单（首次回复，尚未确认时）

首次收到创作需求时，只交付此节，不输出完整生视频提示词。逐项标明“已确认”“待确认”或“可采用默认”。至少询问或确认桌面系统、参考图预留、时长/比例/语言、成年人物与互动关系、字幕 UI。使用简短编号选项，方便用户直接回复。

示例：

```text
制作确认单
1. 桌面系统：A. macOS  B. Windows  C. 自定义（待确认）
2. 参考图：人物 / 桌面 UI / 场景 / 服装。可分别提供；不提供时以文字锁定人物和界面规则。（待确认）
3. 成片：30 秒、16:9、中文。（已确认）
4. 人物与互动：女主为成年角色；男主仅为画外音，全程绝不出镜。（待确认）
5. 字幕 UI：A. 启用屏幕左侧中部的字幕文字、样式/颜色与音频波形动效  B. 不启用  C. 后期叠加准确字幕。（待确认）
```

用户确认后，从第 1 节开始交付。

## 1. 标题与生成设定

标题应简洁描述主题、桌面系统与时长，例如“桌面女友｜macOS 深夜公寓和好互动视频提示词”。随后用 3–6 条写清：时长、画幅、OS UI、是否使用参考图及锁定范围、人物活动区、镜头规则，以及字幕 UI 是否启用。启用时再写字幕安全区。对未提供但已采用的默认项明确标为“默认”。

## 2. 主提示词

给出一个可复制的完整中文提示词，以章节组织，避免只给一段压缩文字。推荐章节：

1. 人物与统一性
2. 整体视觉风格与桌面 UI
3. 场景与构图
4. 字幕互动 UI（启用时）
5. 服装设计（有服装变化时）
6. SINGLE CONTINUOUS SHOT｜精确时间轴
7. 声音设计
8. 表演要求
9. 人物运动
10. 核心生成优先级与负面约束

上述内容按以下优先级组织：

1. 成片规格、同一成年人物与参考图范围。
2. 桌面 OS、稳定 UI 框架、干净桌面、场景、构图和灯光。
3. 主题、人物关系、情绪弧线、服装和道具。
4. 镜头、动作、进出方向、连续性与声音。
5. 仅在启用时写入字幕视觉要求和安全区。
6. 负面约束的核心摘要。

不要在主提示词中塞入互相冲突的分镜说明；精确时间安排写在下一节。

## 3. SINGLE CONTINUOUS SHOT｜时间轴

使用 `00:00–00:00｜段落名`。每段包含：服装/位置、动作、说话者与准确台词、另一方闭嘴聆听的反应、音效、微表情；启用字幕 UI 时再添加字幕状态。女主对男主说话或聆听男主时，明确写“面对镜头”或“看向镜头”；若需回避视线，明确目标是窗外、杯子或道具，并写出何时“重新看向镜头”。微表情须描述可见部位与变化顺序，例如“先轻抿嘴唇，随后眼神从窗外收回，眉间紧绷渐松”。将人物离场、空镜、入场分为独立连续动作。总时长必须与成片规格一致。

涉及换装时，明确写为“真实离场 → 保持空镜 → 画外完成换装 → 沿同一边缘真实进入”；分别给出空镜时长与声音，禁止用镜内瞬时换装代替。

## 4. 字幕与音频 cue sheet

仅在启用字幕 UI 时提供表格：开始/结束、说话者、准确台词、文字样式及颜色、逐字速度、停留/淡出、音频波形动效和混音说明。字幕区固定在屏幕左侧中部，且只出现字幕文字、字幕样式及颜色、音频波形动效；在提示词和负面约束中明确不得出现图标、头像、按钮、手部、话筒或实体物品。生成层若无法可靠出字，仍保留此表供后期覆盖。

## 5. 核心生成优先级与负面约束

先用有序列表列出至少 6 条核心优先级，人物身份一致性、桌面系统一致性、镜头/运动连续性应居前。再用一段高优先级禁令覆盖用户指定的风险，并补充项目特有风险：换脸、肤色/发型/体型漂移、未成年人感、镜头切换或漂移、错误 OS、额外角色、画外音出镜、服装闪烁/穿模、异常肢体、错误进出方向、音画不同步。启用字幕 UI 时，再加入字幕乱码、英文、抢跑和额外文字。

## 6. 生成与合成建议

仅在有帮助时给出：参考图如何使用、该模型的建议分段点、需要后期叠加的 UI/字幕/音频元素，以及验收重点。避免把不确定的平台能力说成已支持。
